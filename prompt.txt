# Bill.Jemsky — Enterprise PDF & Excel Export Requirements

## Professional PDF Generation Engine

Never generate PDFs using:

* window.print()
* Browser Print to PDF
* HTML screenshot export
* DOM-to-image PDF generation

These approaches produce inconsistent layouts across devices and printers.

Instead, implement a dedicated PDF rendering engine.

---

# Recommended PDF Stack

## Primary Engine

React PDF

Purpose:

* Dynamic invoice rendering
* Multi-page support
* Consistent A4 layouts
* Custom fonts
* Table rendering
* Automatic page breaks

---

## Secondary Engine

Purpose:

* PDF manipulation
* Watermarks
* QR embedding
